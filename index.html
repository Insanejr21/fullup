A function do CaveBot,
num clique de distância.

Sai do hunt 3 minutos antes dos horários cadastrados, e segura no templo. Lê os horários direto de storage.eventosPro — cole no seu waypoint e pronto.

Como funciona

01

Lê os horários do fullup. Percorre storage.eventosPro.entries e aceita tanto eventos quanto tarefas do ClickUp (tipo == "clickup").

02

Sai na hora certa. Com ANTECEDENCIA_MIN = 3, o bot vai para o templo 3 min antes do horário e segura lá por SEGURAR_DEPOIS_MIN = 5 min depois.

03

Dungeon tem prioridade. Se o dungeonCheck está ativado com alerta ou indo pra saída, a function libera a dungeon e vai direto para o label de saída.

04

Fora da janela, caça. Sem horário próximo no horizonte de 24h, ela despacha para o label hunt — e não spamma o chat: loga só na mudança de estado.

Parâmetros

ANTECEDENCIA_MIN = 3 SEGURAR_DEPOIS_MIN = 5 USAR_EVENTOS = true USAR_CLICKUP = true RESPEITAR_EVENTOS_OFF = true LABEL_TEMPLO = "templo" LABEL_HUNT = "hunt"
